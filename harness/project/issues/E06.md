## 验收条件

- [ ] 按 CSV 原经纬度展示所有匹配站点，pending/completed/failed 使用一致颜色/符号/语义；聚合数量与成员一致，点聚合展开，点站标进入 map 来源详情。
- [ ] 提供原型 Zoom +/-、fit 当前匹配站点、locate 固定参考位置/方向箭头；无匹配时 fit 有稳定行为；底图错误展示 Retry，受控来源恢复后重试成功。
- [ ] 地图、列表和最近项使用 E03 同一查询集合；概览最近项可进入详情；参考位置标为测试、方向取已有配置，不发起真实定位。
- [ ] MapController 稳定；Toast/同步进度不重置镜头、筛选或焦点；fit/recenter 仅在明确用户动作时执行。
- [ ] 同批次恢复最后落盘的有效中心/缩放，非法/批次变更回退；手势结束合并保存，强杀以最后落盘值为准。
- [ ] 无底图/瓦片错误/缓存缺失仍能搜索列表、详情、保存；清瓦片缓存不清业务库；HTTP freshness 和署名可见，自动化测试用本地或已授权受控底图。

## Harness 执行与关闭证据

最低验证层级：G1 widget/地图 fixture；G2 禁网/冷启/点选由 E08。

在仓库根目录执行（含 `cd app` 的命令除外）：

```sh
python3 harness/run.py quality
python3 harness/run.py build
```

尖括号路径须替换为本任务实际运行目录；计划新建测试/产品入口在实现后运行，不声称当前已有。现有 `test --target` 只支持 `app/test`；`native` 目前仅可靠性 probe；完整 UI/trace 命令由 X00/X02 提供后回填。

关闭时交回：地图/聚合/视口适配组件；计划新增 test/map 控件和受控底图回归；资源/来源说明。原始记录放 `harness/runs/<实际任务运行>/`，报告关联精确候选、配置、设备/数据来源、命令/退出码/日志 hash 与每个需求判定。

开发完成进入 review；独立测试/原生/性能职能分别签对应层级，主控核验后 accepted 并更新 `harness/project/work.json`。缺失/失败/未运行/旧候选不得写 passed；准备材料和网页证据不能证明 Flutter 功能通过。
