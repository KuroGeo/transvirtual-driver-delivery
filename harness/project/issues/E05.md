## 验收条件

- [ ] demo offline 不启动新发送，保存多项后队列保留；重开恢复 offline 不提前清空；online 切换成功后按 seq 单循环发送。
- [ ] 保存时 online、手动重试、重复重连/双击、发送期间新增项和查空退出窗口均不会产生第二消费者或漏唤醒。
- [ ] 真实永不完成的 transport Future 在约定期限内超时释放，能以原 operationId 重试；迟到完成不错误确认其他事件。发送失败/错 ack/本地确认失败保留当前与后续记录；错误后停止，不无限自动重试。
- [ ] pause 不启动下一条；已发送的匹配确认可完成持久收尾；finally 释放运行状态，关闭作用域等待有界在途处理后关库。
- [ ] 进度只统计本地已持久确认项；demo 确认明示模拟；local-client 无服务时不发送/不伪确认，联网也保留队列。
