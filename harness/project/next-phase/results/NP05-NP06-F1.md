## Behavior delivered

- Pure `NavigationScope` binds workspace/principal/generation/dataset locally;
  immutable target plus input and attempt revisions isolate late location,
  route and map callbacks. Future account assembly must replace local scope and
  invalidate the old instance on every session change.
- `RouteRepository` sends only origin/destination coordinates, UTC departure
  and driving mode to `ThirdPartyRoutePort`. The formal default is unavailable;
  no fixed origin, fixture ETA, backend route proxy or service credential was
  added. Supplier errors have bounded timeout and explicit retry, with no cache.
- Each response validates configured provider/revision, attempt/source time,
  expiry, origin/destination/departure, arrival/duration and finite road geometry.
  Device origin is revalidated after the response; age <= 2 minutes, accuracy
  <= 100 m and future tolerance <= 5 seconds. Route display expires when either
  its source expires or its device origin stops being trustworthy. A manual
  start is a user-confirmed coordinate, not a claim of current GPS location.
- `GeolocatorLocationGateway` obtains a single real OS fix only after the user
  requests it. Permission/service/timeout failure keeps the start unspecified
  for Maps. No location tracking stream or background permission is requested.
- `UrlNavigationGateway` builds allowlisted coordinate-only Apple/Google URLs;
  app availability, launch failure and successful handoff are distinct. The
  browser alternative explicitly requests a supported browser view. Unsupported
  launch modes fail instead of silently falling back. Async availability is
  fenced immediately before OS dispatch, including source freshness.
- With an unknown start, Apple Maps opens the exact coordinate destination pin
  using `ll` and `q`, both numeric coordinates. The driver chooses Directions
  and a start in Maps. A supplied start retains driving `daddr/saddr/dirflg`.
  No sample address, customer label or same-name business is geocoded in either
  branch. Root's preview displays the saved coordinate and distinguishes the
  pin-first flow from driving directions. Original station data is unchanged.
- Controller location and launch waits are bounded to 8 seconds. A timed-out
  availability attempt loses its dispatch token. Return requires both a
  successful launch receipt and an observed inactive/paused then resumed
  lifecycle; it never claims navigation started or arrived.
- Navigation has no delivery-write/outbox port. Host SQLite regression verifies
  persisted stops and the exact pending confirmation identities are unchanged.
