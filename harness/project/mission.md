## 本轮来源决议

- 最新直接同步与按入口返回优先旧同步抽屉；保存成功关闭失败表单、保留终态详情。
- R14 最大系统字号修正（#36）：列表、详情和配送摘要使用主要 SafeArea；地图保留完整余量与明确入口，摘要中的最近站点和反馈独立展开阅读并可返回原地图。首次进入列表直接读到站点客户/参考号/状态；搜索筛选独立展开并显式返回结果，反馈不得被固定短 viewport 截断。保留实际系统字号与来源/滚动/焦点，正常字号保持原型；用真实 Inter 几何回归和实际最大字号 OS 图面/用户链验收。
- Waiting only 与跨冷启视口恢复来自架构，明确为架构增量，不能说成当前原型已有控件/持久化能力。
- 失败预设为 Recipient unavailable、Business closed、Address not found、Other。前三项保存选择和 trim 可选备注；Other 使用 trim 非空说明作原因，不重复存第二份说明。历史不存在的备注/原因不补造。
- demo online 设置先落盘再生效；重开 offline 不提前清队列。在途匹配确认允许收尾，但 pause 阻止下一项。永不完成请求须有真实期限，不以测试主动抛超时代替。
- 搜索/筛选/列表位置是会话状态；冷启地图、All、Waiting off、空搜索，恢复有效最后落盘视口，busy/Toast 不恢复。
- 旧 #1–#10 为 not_planned 的历史范围；旧时间盒/同步实现细节不自动约束本轮。预算/设备/容量在 E00/E09 明确，未测不签性能。

## 接口和所有权

启动时主控冻结纯 Dart Dataset/Stop/PendingUpdate 身份，Repository 读取/终态提交/取下一项/确认语义，SyncTransport 单次 ack/error，SyncCoordinator 生命周期，ViewModel 查询/返回来源，以及 MapView 配置/视口事件。当前可靠性基线具体接口见 [contracts](contracts.md)；地图/查询等未实现接口在对应开发任务冻结。

数据开发 owns schema/提交和确认；协调器通过 Repository 而非 SQL；UI 不持有数据库或 HTTP 循环；模型不带 Widget/MapController/SQL row。合同变更后通知消费者并重验。

网页 78/78 仅 browser 历史证据。G1 宿主质量、G2 原生功能、G3 真机/性能、G4 数据与资源、G5 正式发布准备、G6 外部交付分开记录；缺设备/服务/签名时保留真实层级。

R17 是工程准入，不增加产品功能。见 [Harness 审计](../reports/readiness.md)；当前生产 no-go。后续自主开发须补实际环境/门禁/恢复能力，准备试跑不得代签上线资格。
