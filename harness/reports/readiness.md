# Harness 实际能力审计

本次目标是让技能团队能自主推进工程，遇到问题能发现、返工、复验；以真实协作结果验收。本地能力与生产资格分别记录，[状态](status.json) 是当前审计结果，生产判定仍需执行 [gate.py](../gate.py)。这些项目门槛不是外部认证。

## 设计取舍

参考 [OpenAI Harness engineering](https://openai.com/index/harness-engineering/) 的短入口、仓库事实、可读工具反馈、机械依赖约束和 Agent 互审；按这个 Flutter 客户端的风险落地。CLI + JSON + OS flock 足以支撑当前工作，没有另造调度平台或遥测服务。具体业务事件来自实际事务/同步，资源租用保护命令运行，协作 runtime 负责模型 Agent 生命周期。

工程职能收敛为九个岗位，开发和测试也有仓库内 skill。共同规则只放团队协议；业务需求在 mission、接口在 contracts，命令实现只有一份。任务图和审计状态使用 JSON，运行工具只依赖 Python 标准库。一次失败形成具体修复与行为回归，避免把每个观察都扩成通用框架。

## 八项能力

| 能力 | 已实现的执行面 | 生产仍需的证据 |
| --- | --- | --- |
| H01 仓库事实 | 短 AGENTS、当前合同、需求覆盖/DAG/链接检查、独立 Agent 读取和审查 | 当前候选检查持续接 CI |
| H02 环境与隔离 | 固定 SDK/lock、源指纹验证的隔离副本及末态校验、真实 SQLite fixture、配置化专用模拟器、产物保留与单命令清理 | 新来源/平台继续验证同样隔离和恢复 |
| H03 可观察 | 命令退出码/日志/hash、Widget 用户操作、原生 PID/文件库/业务事件可读取 | 完整产品原生 UI 驱动、性能 trace |
| H04 机械边界 | import/export/条件依赖及转导出检查，模型/数据/UI边界；事务/终态/身份故障回归 | 每次接口变更维护对应规则 |
| H05 故障闭环 | 写/确认失败、错 ack、重复触发、错误输入保留、关闭竞态回归；真正进程恢复探针 | 完整地图产品用户链和真机验收 |
| H06 候选门禁 | fingerprint/log hash、SDK/依赖、门禁负例、CI文件；门禁恢复重新检查输入 | required checks、实际发布流程强制接线 |
| H07 中断恢复 | 真 SIGKILL/TERM、继承 FD/inode/flock 的子阶段、活 PID/锁/变更候选与配置/阶段差异拒绝、任务副本回收 | 新外部工具沿用实测生命周期 |
| H08 评测反馈 | 独立交叉审查、未参与优化的取消场景、缺陷前后证据、skill 前向走查 | 后续 skill/工具/合同变化触发风险回归 |

本轮最新已验证组件切面见 [状态](status.json)，正在开发的变更不预签；历史基线证据见 [本次演练](rehearsal.md)，表中“已实现”不是所有生产门槛均通过。

## 生产 no-go 的具体原因

完整地图工作台仍按 [任务图](../project/backlog.json) 实施；可靠性基线不能代签完整产品。模拟器 debug/fake 只能证明本地持久化与进程恢复，真机 profile/release、适用资源许可和签名发布分别需要实际证据。

演练时私有 GitHub 仓库保护设置 API 返回 403：套餐不支持此保护能力。CI 配置随本次 PR 交付，实际运行以 PR checks 为准；required checks 和发布强制路径仍未部署；不通过改公开仓库或购买套餐解决。后续获准远端交付时落实可用的保护/发布方案，再实跑缺证阻断。该外部缺口不阻止本地工程演练和后续开发。

[正式门禁回归](../tests/test_gate.py) 保留：缺失/失败/跳过/旧候选/hash错配/网页冒充原生/debug冒充真机/fake冒充connected/未签产物/授权与交付错配均拒绝。不能用主控评分、合成正向 fixture 或改交付名字覆盖实际缺口。
