# ocean delivery · 地图版反馈修正

这是上一轮反馈的记录，当前版本在 [direct-sync-design.md](direct-sync-design.md) 继续调整了同步入口、概览信息、详情返回路径和图标选择。

沿用地图工作台的鲜橙、奶油白、深棕文字和固定 390 × 844 画布，按用户提出的问题调整控件语义与操作位置。

## 当前设计

1. 当前定位使用蓝色方向箭头，保留 You 标签。固定位置仍在附件站点附近；`map-config.json` 的 `headingDegrees: 35` 是固定原型朝向，未接入 GPS / 罗盘。
2. Pending 用橙色圆形站标中的空心圆，去掉包裹及速度线。列表采用同一空心圆符号；绿勾和失败警示保持一致。
3. Stop list 按当前位置的球面直线距离由近到远展示，增加距离与 Nearest first 提示。最近是 Silverline Supplies 2.4 km、Redwood Wholesale 2.5 km、Skyline Pharma 3.5 km。筛选 / 搜索后仍为最近优先；原始数据顺序不变。
4. 删除底部 Map / Sync 导航。地图始终是工作台，Sync 在左侧工具栏；有待同步更新时显示数量，点开同步抽屉，关闭后返回地图。任务卡打开时工具栏排成紧凑两列，保证同步入口完整可见。
5. 状态选择栏分成名称 / 数量上下两行。选中用浅橙底、细边界和短底线，数量有独立的空间，保留清晰数量与足够呼吸感。
6. 新 App 图标采用鲜橙底和奶油白折线路径箭头，1024px 主文件、180px touch icon、32px favicon 均已生成并接入原型。图标文件与内置图像生成提示词见 `assets/app-icon-design.md`。

没有把品牌图标再次塞进地图页头，保留地图空间。删除底部重复 Map 入口与常驻页签文字；配送结果、地址、客户、时间窗、失败原因和同步数量仍保留。

## 动效与证据

三处动效延续同一种轻量工具手感：

- 首次进入：页头、筛选与概览依次轻微进入。`evidence/round3-feedback/record-entry/`。
- 状态切换：最近站点从列表进入地图任务卡，镜头对准该站。`record-nearest/`。
- 主动作反馈：离线完成，标记和计数更新，再从侧栏 Sync 进入等待队列。`record-sync-tool/`。

每处保留录屏及开始 / 中间 / 结束三帧。面板切换时避免两组文字叠加。聚合更新直接呈现，地图镜头仍有自然过渡，减少快速操作时过期聚合动画影响点选。

首屏与七种主要状态在 `workspace/`，选中 Pending 状态栏在 `pending-filter/`，200% 图面在 `zoom/`。此前地图版证据作为基线保留在 `evidence/round3/`。

## 验证

主 Agent 在最终界面修改后连续运行验证脚本三次，分别 57/57、57/57、57/57 通过。新增检查覆盖固定方向箭头、独立计算的全部距离排序、最近站点真实选中、筛选后排序、原始记录顺序不变、简洁 Pending 标记、无底部页签及侧栏待同步数量；保留离线读回、保存失败、同步中断和底图错误等原有检查；增加了错误提示避让、打开 Sync 时不遮挡队列、单数文案三项检查。

57 项报告为 `evidence/round3-feedback/qa-run-1.json` 至 `qa-run-3.json`。图标尺寸和本地资源可访问另行检查通过。

本轮为存量页面润色，单独进行一次独立图面规范复核，不沿用整体地图改版的数值评分；结果见 `evidence/round3-feedback/visual-review.md`。

原型仍为浏览器 HTML，未接入真实定位朝向、路网里程、导航或服务端上传。距离是直线距离，图标是本原型的新设计。

应用名称按用户指定使用 `ocean delivery`，已统一到地图页标题、页头、对比页与图标说明。
