# 第三版独立视觉评审

按 Oil UI 整体改版协议，由隔离上下文、能看图的独立评审者复核。评审者只接收当前产品约束和截图/录像，不接收源码及制作历史。共四次交接：初评与三次针对问题的复核；评分依次为 **7/10、8/10、8/10、8/10**。

## 初评：7/10

1. 当前蓝点与站点聚合重叠，右侧控件压住聚合。将固定当前位置设在附近但不与站点重叠的位置，地图控件移到西侧空白区域。
2. 聚合外围状态环过薄，绿色/失败状态不易辨认。加宽状态环，收小白色数量中心；保留可访问名称中的状态数量。
3. 任务卡完成按钮与底部橙色 Map 导航争主次。进入任务卡后弱化导航表面，完成操作仍为唯一强橙色按钮。
4. 选站及完成录像的末帧未呈现预期动作。重录真实的 Browse stops → Silverline Supplies → 完成流程，并核对可观察的卡片、绿色标记和队列计数；直接地图标记点击另由交互检查覆盖。

## 第一次复核：8/10

原四项均确认关闭。提出两项细节：首页南侧聚合被地图署名遮挡；列表切换详情时旧文本与半透明新卡片叠加。

为地图初始取景增加底部留白并支持四分之一缩放级；任务卡改为始终不透明的短距离位移动画，旧列表在详情出现时立刻退场。

## 第二次复核：8/10

首页南侧聚合与任务卡过渡两项关闭，但列表状态中署名向上跳到部分聚合环上，属于同一遮挡问题在另一状态中的残留。

## 最终复核：8/10

将署名统一放在筛选栏下方，所有面板高度共用稳定位置；地图取景留出上方署名区，搜索输入也避开该区域。评审者查看最新五状态并排图与选站录像，确认：

> 列表态署名遮挡已关闭。署名稳定放在筛选栏下方，没有再压住聚合数字、状态环或任务卡。此次调整未带来新的必修问题，原必修清单已清零。

最终严格评分维持 **8/10**。到 9 分的差距是密集站点辨识或地图与任务联动尚未达到同品类最好水平；属于进一步设计探索，不是本轮未关闭的必修问题。

保留：独立清楚的当前位置、可读状态环、统一稳定的地图署名、不透明且干净的任务卡过渡，以及用户指定的鲜明橙色。
