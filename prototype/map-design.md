# 第三版：地图配送工作台

## 方向与理由

用户明确要求整个原型以地图为基础，并允许把用户当前位置固定在附件数据附近。地图承担空间判断与站点状态；任务卡承担单站配送操作。延续已确认的鲜明橙色、奶油白和深棕文字，避免换成冷色监控看板。手机目标视口保持 390 × 844，桌面仅展示这个固定画布。

主动作是选中一个站点并记录配送结果。默认显示全部 30 个站点，24 待配送、3 完成、3 失败；没有为了突出待配送而隐藏终态站点。全部坐标直接来自题目 CSV，没有重排地理位置。

## 信息与操作

- 地图全屏铺底，页头仅保留 ocean delivery、区域/站点数量、搜索和一个 Online 开关。
- 橙色圆形站点标记（空心圆）对应 pending，绿色圆形勾对应 completed，红棕警示对应 failed；颜色和图形同时表达状态。
- 密集区域聚合显示站点数量，外围状态环显示成员的状态构成。聚合可访问名称包含三种状态各自数量；点击聚合放大，到街道尺度展开独立标记。
- 蓝色方向箭头与 You 标签表示固定当前位置，和配送状态色区分。位置在 `assets/map-config.json`：`-33.9004, 151.139`，Newtown 附近，处于附件站点的经纬度范围内。配置中的 source 明确记录这是原型固定位置；不把它宣称为 CSV 自带位置。
- 搜索、状态筛选与地图标记、站点抽屉共用同一组筛选结果。保留 Browse stops，便于按客户、地址、时间窗快速找站。
- 选中站点后，镜头将标记置于任务卡上方。卡片依次展示配送状态/编号、客户、突出地址、地区、时间窗和同步状态，完成按钮与当前任务放在一起。
- 完成或失败后，地图颜色/图形、筛选计数、进度与待同步角标立即更新。配送终态与发送状态分别表达。
- Sync 作为地图上的抽屉，显示等待队列与最近确认的更新；避免再建一个独立的仪表盘。

署名保持可见且位置稳定，放在筛选条下方。初始地图取景为这一区域和底部概览保留空间，不再让版权文字随面板高度跳到站点环上。任务卡保持不透明；列表切换到详情时旧文本立刻退场，再由新卡片短距离进入，避免两组可读文本同时重叠。

## 减法

删除首页的大面积任务列表和重复任务标题，把地址从首屏的连续文字改为地理标记；详细地址仍保留在选中任务和站点抽屉，便于核对。原坐标技术数字从主要操作区退出，固定位置说明放在设计文件。删除没有数据依据的路线线条、路线顺序、距离和 ETA 展示。底部 Map / Sync 导航已移除，完成操作保留一个醒目的主要按钮，同步进入地图工具栏。Sync 状态改为一个平面信息条，减少卡片内再套卡片。

## 三处基本动效与证据

1. 首次进入：页头、状态筛选与概览按阅读顺序轻微进入；底图自然加载。证据 `evidence/round3/record-entry/record.mp4` 和三帧。
2. 选站切换：从站点列表选择 Silverline Supplies，地图缩放到实际坐标，任务卡从底部短距离进入；卡片背景始终不透明。证据 `record-select/record.mp4`、三帧与 `transition-1.2s.png`。直接点击地图标记另由交互验证覆盖。
3. 主操作反馈：切换 Offline、进入该站并完成，待配送圆点变为绿色勾，计数更新，任务卡显示记录结果和 Waiting to sync。证据 `record-complete/record.mp4` 和三帧。

三处动作遵守减少动态效果设置。`motion/report.json` 最终探测首次进入 17 个动画元素、操作链 20 个；Leaflet 镜头变换也计入元素数量，数值只用于确认存在动画，不作为设计质量评分。该工具 App 不滚动整页，滚动叙事检查不适用。

## 验证、评审与范围

主 Agent 在最终视觉修改后连续运行 `verify.py` 三次，每次 45/45 通过，报告保存在 `evidence/round3/qa-run-1.json` 至 `qa-run-3.json`。检查覆盖精确坐标、聚合总数、固定位置、真实地图标记点击、搜索/筛选、缩放、状态图形变化、必填失败原因、终态保护、持久化读回、同步中断、写入错误保留输入、底图失败与重试，以及窄屏/桌面布局。

已查看首屏、所有主要状态、详情和失败表单 2 倍截图及动效三帧。最终截图报告没有文字对比度、正文过小、加载错误或横向溢出提示。首屏、任务卡、失败表单和同步队列的判断来自实际画面，不用测试结果代替视觉验收。

依据 Oil UI 整体改版协议进行隔离上下文的独立视觉评审，评审者仅接收产品约束与图面证据。各轮评分和修正见 `evidence/round3/visual-review.md`。

本轮交付为可交互 HTML 设计原型，未实现 Flutter、GPS、路线导航、路线优化、ETA 或真实服务端上传。Online / Offline 为题目允许的应用内控制，发送目标为 fake。底图通过 OpenStreetMap 标准瓦片服务实时加载，需要联网；离线仍有本地站点、固定当前位置、浏览抽屉和配送保存流程。本轮不代替正式 Android / iOS 进程重启或设备验收。

旧设计完整保留在 `archive/round1/`、`archive/round2/`。当前 `style-explorer.html` 对比清单版与地图版；右侧为本地服务 URL，需要预览服务运行。

## 本轮反馈修正：方向箭头、待配送站标与距离排序

- 当前位置始终使用蓝色导航箭头，保留 You 标签和位置光晕。`headingDegrees: 35` 在地图配置中明确保存固定朝向；原型不接入设备罗盘或朝向感应，正式实现可以按设备方位旋转同一箭头。
- 待配送的动感包裹图形换成简洁空心圆站标，地图和列表一致；完成仍为绿勾，失败仍为警示图形。
- Stop list 基于当前配置坐标与附件经纬度计算球面直线距离，并由近到远排列。排序只作用于展示结果，不改 CSV / 原始配送数组；搜索和状态筛选继续保持最近优先。相同距离按站点编号稳定排序。
- 列表展示距离并写明 Nearest first。最近三站为 Silverline Supplies（2.4 km）、Redwood Wholesale（2.5 km）、Skyline Pharma（3.5 km）。这些是坐标距离，不是行车里程或导航路线。
- 最初的三个局部调整由主 Agent 自检；后续导航、状态栏和 App 图标调整另做一次存量页面规范复核，不打分。前述四轮评分属于整体地图改版。最新说明见 `feedback-design.md`，证据单独保存在 `evidence/round3-feedback/`。
