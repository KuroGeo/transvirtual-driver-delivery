# ocean delivery · App 图标设计

已采用鲜明橙色底、奶油白圆环和向右上方的箭头。一个粗线符号表达司机沿站点推进，不塞包裹、卡车、文字或品牌名；小尺寸保持清晰。方形源图不烘焙外圆角，交由操作系统应用图标遮罩。

- `app-icon.png`：1024 × 1024，可用于原型交付与应用图标导出。
- `app-icon-180.png`：180 × 180，已接入 Apple touch icon。
- `app-icon-32.png`：32 × 32，已接入浏览器 favicon。
- `app-icon-source.png`：保留内置图像生成工具的原始输出。

由内置 image_gen 工具生成，未使用 CLI / API 后备模式。按用户最新选择采用第一张圆环加箭头候选。选定后仅按交付尺寸导出 PNG；没有将图标再次塞进地图页头来占用作业空间。

## 当前选定源图

用户指定采用第一张圆环加箭头候选，生成原图保存在同目录的 `app-icon-source.png`。已重新导出 1024 / 180 / 32px，更新原型的图标引用版本，以便刷新后使用选定版本。
